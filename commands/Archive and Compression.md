# Archive and Compression

### Extract `.tar.gz`

```bash
tar -xvzf filename.tar.gz
```

Options:

* `x` — Extract
* `v` — Verbose
* `z` — gzip
* `f` — File

### Extract `.tar.bz2`

```bash
tar -xvjf filename.tar.bz2
```

### Extract Using `dtrx`

```bash
dtrx file.tar.gz
```

```bash
dtrx file.tar.bz2
```

### Extract `.7z`

```bash
7z x file.7z
```
