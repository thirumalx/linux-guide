# Change Shell

### Check Available / Current Shell

```bash
echo $SHELL
```

Displays the user's default shell.

To see the shell currently running:

```bash
echo $0
```

### Change to C Shell

```bash
csh
```

Common shells include:

* `bash` — Bourne Again Shell
* `sh` — Bourne Shell
* `csh` — C Shell
* `tcsh` — TENEX C Shell
* `zsh` — Z Shell
