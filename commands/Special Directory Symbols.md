# Special Directory Symbols

| Symbol | Meaning                              |
| ------ | ------------------------------------ |
| `.`    | Current directory                    |
| `..`   | Parent directory                     |
| `/`    | Root directory / directory separator |
| `~`    | User's home directory                |

Examples:

```bash
cd .
```

Stay in the current directory.

```bash
cd ..
```

Go to the parent directory.

```bash
cd ~
```

Go to the user's home directory.
